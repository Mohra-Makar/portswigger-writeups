## 📖 About

Each write-up follows a consistent structure so findings are easy to scan and compare:

| Section | What it covers |
|---|---|
| **Lab Objective** | What the challenge required |
| **Approach** | Steps taken, including dead ends and pivots |
| **Vulnerability** | Root cause of the flaw |
| **Proof of Concept** | The payload/request that solved it |
| **Impact / Severity** | Real-world consequence of the flaw |
| **Fix** | How it should be remediated |
| **Key Takeaway** | What I learned |
